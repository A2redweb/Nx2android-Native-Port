# nx2android-native

Run the whole [shirai91/nx2android](https://github.com/shirai91/nx2android) porter on an Android phone, with no proot, no PC and no Mac.

Input: a Switch game dump and `prod.keys`. Output: a playable Android app, built and installed on the same phone.

## Status

Design phase. See [docs/DESIGN.md](docs/DESIGN.md) for the open questions and [docs/PRIOR_ART.md](docs/PRIOR_ART.md) for what the proot-based app (`A2redweb/nx2android-android-port`) had to work around.

## Related projects

- Porter: [shirai91/nx2android](https://github.com/shirai91/nx2android)
- Its upstream engine: [seedds/nxnative](https://github.com/seedds/nxnative)
- Predecessor app: [A2redweb/nx2android-android-port](https://github.com/A2redweb/nx2android-android-port)

## Test device

Poco X6, Adreno 710, Turnip driver, Android 14.
